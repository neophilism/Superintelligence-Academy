# SIA-006 Context-sensitive educational overlays

The Academy renders a nonintrusive hint card tied to the currently active shared domain control (`domain.objective`); it fetches a versioned **published** micro-lesson from `/api/lessons`, displays a contextual title and expandable concrete example, and supports dismiss/restore per anchor. Preference uses only the browser’s localStorage; it does not claim persisted server account preferences. Keyboard-operable controls, semantic labels, `aria-expanded`, proper hidden state, accessible loading/failure messages and responsive layout are implemented. The Command Center does not bundle any education overlay or course payload. Full interactive guided-project instruction, tutor conversations and paid courses remain future approved units.
