# SIA-005 Academy versioned lesson registry

Academy publishes 11 editorial-reviewed, genuine micro-hints, one bound to the **actual** shared workspace `domain.objective` anchor in each currently rendered domain. This registry is **Academy-owned**; the shared engine UI knows stable anchors but contains no learning content, ensuring no tutorial content leaks into Command Center. `lib/lessons.mjs` validates the versioned JSON Schema and refuses missing/retired anchors, duplicates, bad prerequisites and cycles. `/api/lessons?anchor=music.objective` is public read-only and serves only published material; it never serves paid or draft content. Paid courseware, tutor, course authoring, UI overlays and authenticated enrollment remain future roadmap work. The initial editorial examples must be reviewed during each product release as engine tools evolve.
